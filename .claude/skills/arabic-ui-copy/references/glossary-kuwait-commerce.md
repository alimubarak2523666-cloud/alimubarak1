# Glossary — Kuwait commerce UI

Use the **Use** column. The **Avoid** column lists common inconsistent or
translated alternatives. Add new terms here when a product decides one.

## Store & catalog

| English | Use | Avoid / notes |
|---|---|---|
| Cart / Bag | السلة | الحقيبة (use only if the brand deliberately says "My Bag" → «حقيبتي»; then never mix) |
| Add to cart | أضف إلى السلة | إضافة للعربة |
| Checkout | إتمام الطلب | الخروج، الدفع (payment is a later step) |
| Drop (limited release) | الإصدار | «دروب» in body text; keep "Drop 01" as a Latin brand label inside `<bdi>` if the brand wants it |
| Sold out | نفدت الكمية | انتهى، خلص (too casual for status) |
| Limited to 200 | عدد محدود: 200 قطعة | محدود بـ200 |
| Coming soon | قريبًا | سيأتي قريبًا |
| Notify me | نبّهني عند التوفر | أعلمني |
| Size / Colour / Variant | المقاس / اللون / الخيار | الحجم (for clothing) |
| Quantity | الكمية | العدد |
| Gift card | بطاقة هدية | كرت هدية (OK in casual marketing only) |

## Payment

| English | Use | Notes |
|---|---|---|
| Cash on delivery | الدفع عند الاستلام | «كاش» only in casual marketing |
| Payment link | رابط الدفع | |
| KNET | كي نت | Keep «KNET» logo; in text «كي نت» |
| Paid | مدفوع | |
| Payment pending | بانتظار تأكيد الدفع | never «فشل» unless confirmed |
| Payment failed | لم يكتمل الدفع | then state whether money was taken, if known |
| Refund | استرداد المبلغ | «ترجيع الفلوس» casual only |
| Subtotal / Delivery fee / Total | المجموع الفرعي / رسوم التوصيل / الإجمالي | |
| KWD | د.ك | 3 decimals: 12.500 د.ك |

| English | Use | Notes |
|---|---|---|

| Area | المنطقة | |
| Block / Street / Avenue / House | قطعة / شارع / جادة / منزل | Kuwaiti address order: المنطقة، قطعة، شارع، جادة، منزل |
| Apartment / Floor | شقة / الدور | «الطابق» is fine too; pick one |
| PACI number | الرقم الآلي للعنوان | from the civil ID address; optional field |

| Delivered | تم التوصيل | |
| Same-day delivery | توصيل في نفس اليوم | |
| Driver | السائق / المندوب | pick one per product; «المندوب» is common in Kuwait |
| Pin location | حدد موقعك على الخريطة | |
